# Manual page

The `proot(1)` manual page is maintained at
[`doc/proot.1`](https://github.com/boxshell-org/box-shell/blob/main/doc/proot.1)
in roff format.

View it:

```console
$ man ./doc/proot.1
```

Install it:

```console
$ install -Dm644 doc/proot.1 ~/.local/share/man/man1/proot.1
$ man proot
```

The option reference on this site mirrors the man page — see
[Command-line reference](options.md).
